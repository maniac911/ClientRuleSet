# V2Box

This output targets V2Box's native routing-import objects and `v2box://routes?multi=...` deep links. It is generated directly from Sukka FileOutput instead of converting Clash text.

Three policy variants are generated by default: `proxy/`, `direct/`, and `block/`. Pick the folder that matches the action you want the imported V2Box route to use.

Each rule set has a JSON route-object file plus one or more `.txt` deep-link files. For example:

`https://raw.githubusercontent.com/maniac911/ClientRuleSet/rules-dist/V2Box/proxy/non_ip/ai.txt`

Open the raw text in Safari, copy/open the `v2box://routes?multi=...` URL, and V2Box can import the routes. Large rule sets are automatically split into `.part01.txt`, `.part02.txt`, etc.; import every part in numeric order.

Verified/conservative mappings: exact domain -> Domain/full, suffix -> Domain/regexp, keyword -> Domain/keyword, wildcard/DOMAIN-REGEX -> Domain/regexp, GEOSITE -> Domain/full with `geosite:`, IPv4/IPv6 CIDR -> IP/full, and GEOIP -> IP/full with `geoip:`.

Fields whose V2Box route-object/deep-link behavior is not verified are not guessed. See `_report/unsupported.txt` and `_report/warnings.txt`.
